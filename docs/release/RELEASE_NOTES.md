# ResearchClip 5.0.0 候选发布说明

状态：**未公开发布，发布验收未全部通过**。实际origin为[ResearchClip-Codex](https://github.com/wpy-sketch/ResearchClip-Codex)。本文件不是已发布Release公告，不提供虚构下载地址。

## 本轮变化

- 右侧G切换为工作台内嵌网页：地址栏、Google搜索、前进后退、刷新/停止、50%–200%网页缩放；返回保留原编辑会话。Windows独立WebView2无资料库IPC能力，外部Chrome入口保留。
- 紧凑浏览器工具栏及边界裁剪适配窄分栏和低高度；新版四色选区文档图标；38章有序指南增加浏览器操作示意和排错。

- 当前PDF最多30,000条Zotero标准批注：六类显示、按类型/文字/颜色筛选、分页浏览与列表定位。
- ink保留矢量路径，text保留字号和旋转，投影到ResearchClip原生图层；不与私有手写混存。
- 每次100条读取，超大响应逐步缩小，条件刷新可复用同版本缓存；按页面建立索引，密集图层分帧绘制。
- 非ink五类提供本地API写入路径、参数校验、条件版本、待处理队列与复读；已在独立Zotero10.0.6资料库完成五类创建、改字改色和删除，共15项操作复读核实。
- 修复首次确认Zotero来源后批注来源列表不更新；修复最大化面板时不能切换至其他工作台面板。
- PDF划词工具栏、复制、外部Google翻译、受冲突检查的快捷键；可调整右侧导航宽度并完整保留文件名。
- 真正Chrome负责账号及书签同步；应用内嵌WebView2不等于完整Chrome，不读取其账号。下载和受限制网页可转用Chrome。
- 沿用Step2真实组件安装与CPU单行OCR；当前采用随主程序审核内置的固定组件清单和SHA-256，自动更新停用。
- 新增Windows发布工作流、严格发布门槛、真实资产引用验证及发布后匿名下载哈希核对。

## 数据兼容

应用版本统一为5.0.0，应用标识io.researchclip.desktop，SQLite21；本轮没有新增迁移或批量升级依赖。OCR包装版本1.0.1，真实权重与字典保持固定SHA；Connector1.0.1，目标Zotero10.0.6。新增兼容回归确认：4.4.0旧签名组件文件保留，应用升级后不兼容组件停用并提示更新，不静默删除。

## 5.0.0 真实验收修复

- Zotero宿主实际拒绝缺少`applications.zotero.update_url`的XPI。补全本仓库插件更新目录声明；发布管线生成并校验`zotero-updates.json`，与相同Release的真实XPI版本、URL及SHA绑定。候选URL尚未公开可用，不伪造线上状态。
- 在独立Zotero10.0.6实际安装Connector1.0.1，确认Enabled、工具菜单、右键菜单和用户主动配对；测试PDF已交给现有ResearchClip实例。
- 修复确认来源尚在落盘时快速切换导航导致批注页保留“尚未关联”的竞争；持久化完成后刷新归PDF会话所有，不受来源面板卸载影响；添加延迟确认与失败测试。
- 修复真实Zotero对选文/评论执行`trim().normalize()`后误报待核实和冲突的问题；只按已验证的ECMAScript去首尾空白与NFC规则规范提交值，保留本地原始草稿、内部空白、精确坐标与条件版本。不将NFKC、实际内容差异或坐标变化视为一致。
- 修复JSON往返造成矩形坐标末位浮点差异时误报冲突；仅允许最多4个f64 ULP且绝对差不超过1e-8，实际坐标、页码、形状与内容变化仍拒绝。原待处理高亮按同一键复读成功，未重复创建。
- 修复使用指南六类批注流程图未注册到应用内图片映射，保留离线可读性。
- 新增宿主Manifest防回归和更新目录篡改拒绝测试。完整测试计数与最终包身份见[最终报告](../qa/FINAL_RELEASE_REPORT.md)。

## 发布前尚需完成

最终安装器重新构建与验收、公开资产下载及独立Windows机器验收仍未完成。真实Zotero已完成XPI安装、配对、写入授权、五类CRUD、变化通知、重启重新配对和反向定位；群组库、云账号同步及物理混合DPI仍需人工验收。详见[最终发布报告](../qa/FINAL_RELEASE_REPORT.md)。

未验证的公式、视觉语义模型及许可证未明确的浏览器安装归档不进入正式可安装目录。没有新增PDF导出或独立备份恢复系统。

## 用户确认的免密钥交付方式

取消正式Catalog与Tauri Updater公私钥配置。主程序和可选资源采用手动发布；客户端仅安装编译内置清单中的精确资源，继续执行HTTPS、SHA-256及真实推理检查。自动更新停用，不生成latest.json或Updater签名；手动下载新安装包升级。该变更不放宽Zotero权限、原生能力、文件覆盖或核心验收门槛。
