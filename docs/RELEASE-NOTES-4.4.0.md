# ResearchClip v4.4.0（开发验收中）

当前PDF的Zotero标准批注读取上限提升至30,000条，完整搜索与25/50/100条分页浏览，支持颜色筛选、页码/类型/修改时间排序和原文定位。密集页面分帧绘制，编辑和同步按需展开；批量比较与缓存共同提交，失败保留旧快照及本地修改。

合并此前未发布的专用Zotero Connector、认证本机配对、来源下载助手和自定义工作台布局。更新原创多色文献图标与顺序编号图文指南。用户取消IDE开发，本版不包含IDE原型。

ResearchClip SQLite升级至schema21，仅扩大本应用缓存约束，保留旧JSON；原Zotero数据库、PDF和Markdown不重写。预算、兼容范围和手动确认要求见[指南35章](USER_GUIDE.md#35-浏览当前pdf的全部zotero批注)。无Markdown→PDF或独立备份恢复系统。

**未正式发布**：必须先通过用户要求的独立真实Zotero验收、最终Windows安装验收与全量附件核验。测试与未通过项见[QA](qa/RELEASE-4.4.0.md)。
