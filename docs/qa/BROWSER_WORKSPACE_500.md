# 应用内浏览与完整功能复查（5.0.0）

2026-10-29；基于已有工程增量实现，不重建项目。本版尚未公开发布；GitHub状态与最终安装包身份见[发布报告](FINAL_RELEASE_REPORT.md)。

## 实现与修改范围

新增`ResearchBrowser.tsx`、`browser.ts`和Rust `research_browser.rs`，复用右侧G入口及原资料工作台；提供HTTP(S)地址、Google搜索、导航、停止、缩放、返回和错误重试。采用Windows原生子窗口，不改变现有主窗口命令类型；架构见[决策](../architecture/RESEARCH_BROWSER.md)。无新增依赖、无新增数据库迁移。

工作区原有左右/上下/标签预设、比例、拖动、显示隐藏和布局保存继续保留。新增网页工具栏换行与低高度横向工具栏、窗口/面板边界裁剪、CSS/DPI物理坐标映射。图标简化为原创四色选区框与文档；没有复制Google商标。指南按1–38章顺序组织，新浏览器章含流程示意、排错和示例。

主能力收紧到main视图，远程网页无IPC能力。临时浏览会话不共享Chrome账户；不承诺全部网站、Google登录、Chrome书签同步。文件下载和设备权限交由外部Chrome，不能通过网页获取本地科研数据。

## Windows人工验收

使用独立资料目录：输入未保存笔记→G→访问公开网页→拖动分栏、切换布局、缩放→返回笔记核对内容及撤销→打开应用模态框核对网页层隐藏→再次进入恢复网页→正常退出。网页加载失败应能停止、更改地址或返回工作台。确认未写入用户日常资料；原生测试不能替代另一台干净Windows安装验收。

用户确认没有可用独立Windows，本轮交付为源码上传及Release草稿，保留此项验收，不转为公开稳定版。浏览器原生结果位于本地`artifacts/research-browser-v500-r5/report.json`；当前网络未确认Google首页加载成功，example.com/example.org已实际打开。OCR组件当前原生回归采用明确SHA校验缓存，实际CPU推理、重启离线进程代理和既有SQLite/Markdown联动通过，先前真实上游网络下载结果仍分开保存。指南渲染回归通过38章、286示例、76张图片解码、明暗主题、7种宽度、字号及三分栏独立撤销；这是本地Edge渲染测试，不是全部Windows硬件验收。
