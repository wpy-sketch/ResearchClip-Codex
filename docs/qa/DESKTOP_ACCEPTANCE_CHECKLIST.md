# 桌面恢复后的真实验收清单

状态：部分已通过，2026-10-29持续验收。桌面已恢复，独立Zotero10.0.6安装、配对、来源及五类CRUD已通过。依据用户最新要求取消Catalog/Updater公私钥配置，采用固定编译清单与SHA-256，停用自动更新。此清单不构成整体验收回执，不触发发布。

## 1. 环境与数据保护

- 由用户先恢复可交互Windows桌面并告知。保留既有0x80070005失败记录，不以HTTP、Mock或CDP应用测试替代Zotero宿主。
- 使用独立Zotero10.0.6配置、独立测试资料目录及练习PDF。核对实际进程/profile，禁止在用户日常文献库运行创建、删除或故障注入测试。
- ResearchClip使用独立测试资料。记录所测EXE/XPI的SHA、版本与Windows/DPI。不同构建字节不得沿用旧回执。
- 当前候选采用手动安装升级，无需公私钥配置，不生成latest.json或.sig；文件一致性、真实宿主、最终安装包与公开下载核对继续保留。

## 2. Zotero插件与来源

1. 按Zotero标准插件管理流程安装确切XPI，保留安装与兼容性结果。不改签名限制，不静默安装。
2. 在ResearchClip设置开启本机桥，使用界面显示的配对码完成明确授权；不记录或提交凭据。
3. 从测试文献右键“使用ResearchClip打开”，核对library类型/ID、item key和attachment key；从API/插件读取真实身份，不从路径猜测。
4. 重复打开同PDF应聚焦已有标签；指定页码或批注定位准确；反向定位回相同Zotero资料库。
5. 取消配对、Zotero退出及重新启动，确认原编辑会话、已落盘草稿与失败修改仍保留。

## 3. 六类标准批注读取与导航

在Zotero测试文献创建高亮、下划线、便签、自由文本、区域及ink。逐项核对文字、颜色、页码、范围、ink路径和自由文本字号/旋转。测试0/90/180/270度、不同PDF缩放、窄分栏与高DPI。

在ResearchClip按六种类型筛选，再按文字/颜色筛选，点击PDF区域定位列表，点击列表返回PDF。文件名应完整换行，宽面板导航可拖动和键盘调宽。不可识别位置须明确显示诊断。30000条模拟数据性能回归已完成；如需真实规模验收，应使用专门生成且独立的测试库并单独记录，不把模拟结果计作真实宿主数量证明。

## 5. PDF和Markdown闭环

测试选择文字后的划词工具栏、类型选择、复制、有限快捷键及中文输入法。只有用户主动翻译才发送短选区到外部网页，不能自动上传PDF。

截图本机PDF选区后插入Markdown当前光标，注释在图下；移动时图文整体移动。实际Ctrl+S经Windows系统文件选择器保存，关闭、重开、应用重启后检查源码及相对图片路径，再从截图返回同一PDF位置。已有render-only回归不替代这项文件选择器闭环。

本轮实际通过216 DPI截图、图下注释、中文空格路径的原生保存和打开对话框、关闭并重开、相对PNG解码、数学/表格/未知扩展源码逐字核对、来源跳转高亮与Markdown会话保留。应用重启后的该文档闭环待最终安装版复核。物理混合DPI/HDR、多显示器、中文输入法组合尚未实测。

## 6. 真正Chrome入口

点击最右侧Google入口，再点“使用Chrome打开Google”。观察真正Chrome进程和Google首页，保留ResearchClip PDF/Markdown草稿。Chrome不存在或启动失败应有明确错误。

由用户在Chrome自行管理账号与书签同步；不会把Google网页登录等同Chrome同步。若用独立测试Chrome账号演练，核对Chrome自身同步状态，不读取用户凭据、不擅自修改个人书签。不要求工作台内嵌Chrome。
