# ResearchClip5.0.2最终发布验收（进行中）

本轮范围：最左侧Google浏览器入口、应用内网页、本地一键书签、使用指南顺序及发布。5.0.1已实际公开并验证14个资源；最后视觉复核发现内置指南仍有5.0.0未发布导言，因此以5.0.2补丁修正，不覆盖旧Tag或资产。历史结果见[5.0.1报告](FINAL_RELEASE_REPORT-5.0.1.md)。

仓库为[ResearchClip-Codex](https://github.com/wpy-sketch/ResearchClip-Codex)，版本配置5.0.2。当前5.0.2尚未公开，构建与发布结果后补。SQLite仍21，无新增依赖或数据库迁移。

## 完成内容与设计

- 最左侧主导航Google浏览器，地址/搜索、前进后退、停止、重载、缩放；原生WebView2在工作台内显示网页，PDF和Markdown会话保留。
- 书签新增、编辑名称/网址、排序、确认移除、重启保留、一键打开，沿用SettingsService原子设置落盘；最多32个，不增加研究资源ID或存储服务。
- 公开HTTP(S)校验、远端无应用IPC；仅本机书签，Chrome账号同步由真正Chrome处理。
- 指南保持1–38章及旧帮助目标，六条阅读路线、默认章节概览、287例/77幅离线图；修正未发布导言及Connector状态。
- 精确钉住5.0.0/5.0.1旧清单证明，仅为相同模型文件迁移兼容元数据，真实文件校验与CPU自检成功后启用；非法或未知证明拒绝。
- Git固定XPI五个源文件的原始字节；自动换行开/关两种实际检出均与已发布包逐字一致。旧打包作业哈希不一致时正确拒绝，没有修改校验来放行。

修改文件见[本轮清单](CHANGED_FILES-5.0.2.md)，设计见[浏览器架构](../architecture/RESEARCH_BROWSER.md)。

## 验收范围及限制

用户2026-10-29明确接受已列未验收项，按本机隔离范围正式发布。本补丁沿用此范围，并用本版源/安装包/XPI精确摘要重新签署事实回执；不会将该确认写成干净Windows通过。

仍需人工：另一台干净Windows/虚拟机的生产首次启动与真实旧版安装升级、物理混合DPI/HDR/多屏、当前原生Markdown保存重开对话框、当前Zotero写入复测、真实群组权限和云账号同步。Google首页当前网络未确认，example.com/example.org真实可用。公式/语义模型、未核实浏览器归档不进可安装目录。

按用户要求，Catalog及Updater公私钥配置已取消。仅精确编译清单、HTTPS/大小/SHA；自动更新停用，手动NSIS升级，不生成.sig或latest.json。安装包未做Windows代码签名；原生OCR运行时Microsoft签名和SHA需实际核对。未新增IDE、Markdown→PDF或独立备份恢复。
