# ResearchClip v4.2.8（开发中，未发布）

专用Zotero Connector运行在Zotero内部，通过用户手动配对的认证本机协议向现有ResearchClip实例发送完整文献/附件身份、PDF位置及有界变化提示。复用已有PDF、来源确认与标准批注同步服务。

- 支持打开请求、重复内容聚焦、页码/批注核对及反向定位回执。
- 连接默认关闭，一次配对码120秒有效；取消或失联撤销能力，已加载PDF保留。
- 插件来源助手只读取用户指定的公开GitHub正式Release，核对源站SHA-256后另存为，不覆盖文件或静默安装。
- 自定义左右、上下和标签布局及20%–80%比例，保留既有编辑会话与动态Markdown规则。
- 指南增加第34章、12项练习和离线图示，调整可缩放表单、按钮与原创新图标。

沿用SQLite schema20，无数据库迁移；httparse1.10.1由已有传递锁定版本声明为直接依赖，保留MIT许可。精确Zotero目标10.0.6；其他版本没有验证。插件、批注同步与Markdown/私有手写的边界不变，不改原PDF，不直接写Zotero SQLite。

真实XPI安装、菜单和配对链路等待Windows桌面可操作后的独立配置验收。用户明确要求通过后发布，因此此文不是正式Release完成声明。实际结果及待验收项见[验收记录](qa/RELEASE-4.2.8.md)。
