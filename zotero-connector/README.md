# ResearchClip Zotero Connector 1.0.1

专用桌面插件，不是Zotero官方浏览器Connector，也不是Tauri插件。本插件原创源码MIT许可；不包含Zotero源码。当前仅针对10.0.6核查，真实插件加载/接口验收仍在进行，不把编译和Mock结果冒充宿主通过。

构建：在仓库根运行 `python scripts/build-zotero-connector.py`，输出不覆盖已有文件的XPI及SHA256。XPI为标准ZIP，manifest.json和bootstrap.js位于根目录。

安装：先核对Release来源和摘要，在Zotero“工具→插件”齿轮菜单选择“从文件安装插件”，选择XPI并自行检查安装和安全提示。不降低签名检查，不强制启用不兼容插件；不将其放进Tauri插件目录。

连接：在ResearchClip设置中启用专用Connector，复制一次配对码；在Zotero“工具→ResearchClip Connector连接…”粘贴并显式连接。配对码120秒单次有效；token只在两端内存。收起面板保留连接，取消连接清除临时能力，重启需重新配对。

打开：文献/附件右键“使用ResearchClip打开”。父文献使用Zotero首选PDF；精确选择附件则打开该附件。连接面板可指定页码或同附件批注key。独立无父文献附件目前不能伪造父item key，会明确失败。文献信息仍未核实，Local API关闭时普通PDF可读，身份绑定与批注跳转须另行核对。

反向定位：ResearchClip必须已有完整来源关联，并与当前Zotero实例一致；根据个人库/群组库和两种key查找，不能凭文件名推断。变化通知只作为读取提示，不自动写入批注；私有手写与Markdown不参与。

恢复：掉线/停止/心跳过期后重新配对。打开回执只表示排队，不代表PDF已加载。不要在结果不确定时盲目重复操作，先检查桌面队列及已有PDF标签。用户可随时取消连接；已有PDF与研究资料保留。

人工清单：正常安装/禁用/重启，中文路径、父文献和精确附件、个人/群组相同key、页码与批注、已运行桌面实例、离线API回退、变化提示与关闭后监听清理、取消/超时恢复。需要在独立Zotero配置和练习文献验证，不能直接修改ZoteroSQLite或正式文献文件。
